# Student Pass/Fail Prediction using Decision Tree

A beginner Machine Learning project using Decision Tree Classifier.

The model predicts whether a student will pass or fail based on:

- Study Hours
- Sleep Hours

## Features

- Train/Test Split
- Decision Tree Classifier
- Accuracy Score
- Confusion Matrix
- Tree Visualization

## Libraries Used

- Pandas
- Matplotlib
- Scikit-Learn
